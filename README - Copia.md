# Linguagem-de-Marcacao
# 📚 Linguagem de Marcação — Técnico em Desenvolvimento de Sistemas

## 👋 Sobre a matéria

A disciplina de **Linguagem de Marcação** faz parte do curso Técnico em Desenvolvimento de Sistemas do **SENAI**. Nela, aprendemos os principais conceitos utilizados na criação e estruturação de páginas web.

## 🌐 Principais conteúdos

Durante a matéria, são estudados conceitos como:

* **HTML** — estrutura das páginas web;
* **Tags e elementos HTML** — organização dos conteúdos;
* **Títulos, textos, imagens e links**;
* **Listas e tabelas**;
* **Formulários** — criação de campos para interação com o usuário;
* **Estrutura básica de uma página HTML**;
* **Organização e formatação de conteúdos para a web**.

## 💻 Tecnologias utilizadas

* 🟠 **HTML5**
* 🖥️ **Visual Studio Code**
* 🌐 **Navegadores para testes**

## 🎯 Objetivo da disciplina

O objetivo é aprender a **criar e estruturar páginas web**, desenvolvendo uma base importante para a construção de sites e sistemas. A disciplina também ajuda a compreender como diferentes elementos de uma página são organizados e apresentados ao usuário.

## 🚀 O que estou aprendendo

Com essa matéria, estou desenvolvendo conhecimentos em **desenvolvimento web**, aprendendo a transformar ideias e conteúdos em páginas estruturadas, organizadas e visualmente agradáveis.
